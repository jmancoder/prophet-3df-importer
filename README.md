# Mr. Bean 3DF Importer
This Blender add-on lets you import 3DF scene files from the PC release of Mr. Bean and possibly other [Prophet Engine](https://www.pcgamingwiki.com/wiki/Engine:Prophet) games.

## Usage
1. Extract the GAME.BRA archive using this command line tool: https://github.com/RikuKH3/brapack/releases/tag/1.4.
2. Download the latest version of this addon from the [releases](https://github.com/jmancoder/mr-bean-3df-importer/releases) page and install it in Blender.
3. Click **File->Import->Mr. Bean Scene (.3df)**, select a .3df file, and click **Import 3DF**
