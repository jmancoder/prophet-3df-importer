# Prophet 3DF Importer
This Blender add-on allows you to import 3DF scene files from certain [Prophet](https://www.pcgamingwiki.com/wiki/Engine:Prophet) engine games. It has been tested on the following games:
- Mr. Bean [PC]
- Home Alone [PS2]

## Usage
1. Optionally extract the GAME.BRA archive using this command line tool: https://github.com/RikuKH3/brapack/releases/tag/1.4.
2. Download the latest version of this add-on from the [releases](https://github.com/jmancoder/mr-bean-3df-importer/releases) page and install it in Blender.
3. Click **File->Import->Prophet 3DF (.3df)**, select a .3df file, and click **Import 3DF**
